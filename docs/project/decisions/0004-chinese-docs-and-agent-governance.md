# ADR 0004：中文文档与 Agent 元治理

- 状态：已接受
- 确认日期：2026-08-16

## 背景

首版项目记录使用英文，根 `AGENTS.md` 同时展开长期原则、当前进度和具体契约，既不便于用户审阅，也容易让后续 Agent 把过期状态当作规则。

## 决定

- 面向人的仓库文档、ADR、迭代记录和开发汇报默认使用中文。
- 代码标识符、协议字段、命令、包名和标准许可证正文保留原文。
- 根 `AGENTS.md` 只承载长期元指引：产品方向、文档路由、架构护栏、设计策略、思考规则和流程入口。
- 当前进度、阻塞项和唯一下一步只在 `PROJECT_STATE.md` 维护。
- 完整架构、Tool 契约、开发发布流程分别由独立文档维护，根指引只链接，不复制正文。

## 影响

后续新增或修改项目记录必须使用中文。任何会随阶段变化的状态都不得写回 `AGENTS.md`。
