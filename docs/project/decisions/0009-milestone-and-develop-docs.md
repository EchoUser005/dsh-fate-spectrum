# ADR 0009：功能里程碑与开发技术方案分层

- 状态：已接受
- 确认日期：2026-08-16
- 扩展：ADR 0006

## 背景

活动里程碑同时承载功能目标、精确目录树和实现 TODO 时，用户难以快速判断版本是否偏离；长期架构也容易被当前 MVP 的文件布局污染。

## 决定

- 活动里程碑只描述用户功能目标、版本范围、验收节点、决策门和完成定义。
- 当前版本的业务流水线、精确代码树、文件职责、实现顺序和测试设计进入 `docs/develop/`。
- 长期架构只保存依赖方向、TypeScript 判断原则和何时开启新边界，不记录当前文件树。
- `AGENTS.md` 根据任务触发条件引导 Agent 逐层读取，不复制专项文档细节。
- 版本完成后，里程碑与对应 develop 技术方案分别冻结并归档。

## 影响

用户日常先审核里程碑；只有需要判断代码组织或实现路径时才展开 develop 技术方案。实现细节不能反向扩大版本范围，里程碑也不再维护第二份代码树。
