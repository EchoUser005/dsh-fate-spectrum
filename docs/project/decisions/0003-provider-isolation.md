# ADR 0003：Provider 隔离与保守并发

- 状态：已接受
- 确认日期：2026-08-16

## 背景

候选八字与紫微计算库使用不同模型，且都存在模块级可变配置。目前两者都没有直接表达未知出生时辰的完整建盘接口。

## 决定

- 八字和紫微必须作为两个独立 Provider/Executor，通过独立端口接入。
- 不得把两套计算系统合并为一个计算模块。
- 在隔离测试证明所有路径不会发生跨调用污染前，不得声明 DSH Tool 并发安全。
- 未知时辰字段和计算约定默认值必须等专门探针完成后与用户共同确认。

## 影响

Phase 0 不安装 Provider。探针阶段必须包含重复确定性和 A/B 隔离测试，完成评审后才能冻结公共契约。
