# 迭代记录：Phase 0 仓库基建

- 日期：2026-08-16
- 分支：`chore/phase-0-foundation`
- 状态：已完成并通过 Node.js 24 收口验证

## 目标

把已确认的公开设计源整理为仓库文档，并建立最小的 DSH 官方对齐 TypeScript/pnpm/Vitest 基线，不实现 Provider 或 Tool。

## 范围

- 仓库文档与架构图片。
- 构建产物、`.local/` 和本地私有资料的统一忽略规则。
- 项目状态、ADR、迭代、变更日志、许可证和第三方声明。
- Strict TypeScript、ESM 构建、格式化、静态检查和一个人工构造的基建测试。

## 明确不做

- 不安装 DSH、Cordis、tyme4ts 或 iztro。
- 不实现 Provider、Tool Schema、canonical output、Renderer 或 Cordis 注册。
- 不决定计算约定或未知时辰行为。
- 不使用真实生日 fixture。
- 收口前不 commit；未经单独授权不 push、创建 Tag/Release 或发布 npm。

## 实际改动

- 整理四份公开设计文档并放入仓库正式位置。

| `corepack pnpm run test`                            | 通过，1 个文件、1 个合成测试          |
