# 迭代：v0.1.0 Bundle 与发布候选

- 日期：2026-08-16
- 分支：`feat/tool-skeleton`
- 目标：把已经验收的开发态排盘插件变成可由 DSH Profile 安装的预构建 Bundle，并冻结公网优先、本地备用的分发入口

## 用户确认

- npm 托管是普通用户首选；本地安装方式保留在 README。
- package 版本从 `0.0.0` 提升为 `0.1.0`。
- canonical `schemaVersion` 从 `0.1.0-dev.3` 提升为 `0.1.0`，不改变字段、状态、错误或 Observation。
- 完整视太阳时不使用半成品算法阻塞首版发布，继续作为未来能力诚实披露。

## 改动

- `package.json` 增加正式包元数据、公开 npm 配置、`dsh.bundle.patch`、预构建 `prepack` 和打包／Profile smoke 脚本。
- 增加包内 `cordis.patch.yml`，通过稳定包名注册 `fate-spectrum`，不包含本机路径。
- `@deepseek-ai/dsh-tools@0.1.0-rc.6` 与 Cordis 保持宿主 peer 边界，插件不携带第二份 DSH 运行时。
- 发布物严格收束为 `lib/`、Bundle patch、README、LICENSE、第三方声明和 package manifest。
- README 新增 npm 推荐安装、升级、本地 tarball 与配置验证步骤。
- GitHub CI 改为检查实际 tarball 内容，并在隔离 DSH Home 中完成 Profile 安装与 Web 启动 smoke。
- Tool 契约、技术方案、里程碑和 ADR 同步正式版本与分发边界。

## 测试证据

- Node.js 24.19.0：格式、Lint、类型、27 项测试、离线测试、构建和发布包内容检查通过。
- Node.js 22.19.0：类型、27 项测试和构建通过。
- `.local/pack/dsh-fate-spectrum-0.1.0.tgz` 只包含 7 个允许条目，不包含 `src/`、`tests/`、`.local/` 或开发方案。
- 干净 `web` Profile 通过 tarball 安装后，manifest 自动加入 `dsh-fate-spectrum` Bundle；`--dump-config` 出现 Bundle 层和 `fate-spectrum` 插件行。
- 隔离 DSH Web Profile 在 Node.js 22.19.0 与 24.19.0 下均启动成功并返回 HTTP 页面，测试后进程已关闭。
- npm 注册表查询 `dsh-fate-spectrum` 返回 404；发布当刻仍需再次检查包名并获得明确授权。

## 当前停点

- 发布候选只进入本地功能分支，尚未 push，也未创建 PR、Tag 或 GitHub Release，未执行 npm publish。
- GitHub CI 真实结果只能在 push 并创建 PR 后取得。
- npm 发布后必须从公共源重新安装，并执行一次最小 Profile smoke。
