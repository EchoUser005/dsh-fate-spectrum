## 3. 已验证能力

已知公历日期、时分和性别时，Tyme 可以离线映射：

- 公历转农历与四柱；
- 年、月、日、时柱的干支；
- 地支藏干及本气／中气／余气；
- 柱干和藏干相对日主的十神；
- 纳音、旬空；
- 日主对各柱地支的十二长生，以及各柱自坐；
- 顺逆、起运偏移、交运时刻；
- 大运干支、十神、起止周岁与起止年份。

同一合成输入重复 20 次只产生一份结果。默认换日、晚子时仍算当天、`lunar_sect_1` 和 `lunar_sect_2` 均可显式切换；探针使用 `try/finally` 恢复 Tyme 的模块级 Provider，A/B/A 结果一致。

## 4. 共享状态约束

`LunarHour.provider` 与 `ChildLimit.provider` 是模块级可变状态。正式 Adapter 必须：

1. 在一次同步计算开始前保存原 Provider；
2. 按本次调用快照设置换日与起运 Provider；
3. 不在 Provider 被替换期间产生异步让出；
4. 在 `finally` 中恢复原值；
5. 在跨调用隔离证据完成前不声明 Tool 并发安全。

第三方对象、枚举和异常不得越过 Provider 边界。

## 5. 未知时辰证据

探针否定了“未知时辰永远只缺时柱”这一假设。

### 5.1 晚子时影响日柱

合成日期 `2000-01-03`、男、`lunar_sect_1`：

| 候选时刻 | 年／月／日柱     | 第一大运 | 起运周岁 | 交运年份 |
| -------- | ---------------- | -------- | -------- | -------- |
| 00:00    | 己卯／丙子／庚申 | 乙亥     | 9        | 2008     |
| 23:59    | 己卯／丙子／辛酉 | 乙亥     | 10       | 2009     |

在默认 `zi_hour_next_day` 下，未知时辰覆盖 23:00 后的候选，因此日柱、精确起运时间、起运周岁和交运年份不能安全压成一个值。

### 5.2 节气交接影响年柱、月柱与大运序列

Tyme 计算 `2023` 年立春为 `2023-02-04 10:42:33`。同一天：

| 候选时刻 | 年／月／日柱     |
| -------- | ---------------- |
| 09:00    | 壬寅／癸丑／癸巳 |
| 12:00    | 癸卯／甲寅／癸巳 |

出生日期正逢节气交接时，未知时辰还可能影响年柱、月柱、起运顺逆与大运干支序列。

## 6. 已确认的未知时辰语义

用户确认未知时辰返回完整候选，而不是要求补问或制造默认时刻。正式 Provider：

- 枚举当天全部 1440 个民用分钟；
- 按年／月／日柱、日主、柱内事实与离散大运事实压缩真正不同的候选；
- 为每个候选标明适用时间范围和交运时刻范围；
- 不返回时柱及任何时柱相关事实；
- 由 Observation 告诉模型共同事实可以直接分析，差异事实必须按候选作条件式解读。

完整不变量见 [ADR 0013](../project/decisions/0013-unknown-birth-time-candidates.md)。

## 7. 本探针未验证

- 完整视太阳时：Tyme 不提供城市解析、经度修正和均时差的一体化能力，仍由独立时间引擎负责。
- 完整视太阳时校准后的未知时辰候选边界。
- 干支作用、神煞、命理解读和紫微能力。
